# 01_PROJECT_CONTEXT.md

## Project Name
Cinerva

## Project Type
Movie Ticket Price Comparison Platform

## Vision
Help moviegoers compare the actual final ticket price across multiple booking platforms before making a booking decision.

## Problem Statement
Movie ticket platforms often show a base ticket price first and reveal convenience fees, handling charges, and taxes later during checkout. Users must manually compare multiple platforms to find the best deal.

## Solution
Cinerva provides a single platform where users can:
- Search movies
- View movie details
- Watch trailers
- Compare ticket prices
- Compare convenience fees
- Compare taxes
- Identify the cheapest final price
- Redirect to the preferred booking platform

## Target Users
- Students
- Movie enthusiasts
- Families
- Frequent moviegoers

## MVP Goals

- Trailer integration
- Ticket price comparison
- Cheapest option highlight
