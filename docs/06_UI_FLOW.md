# 06_UI_FLOW.md

## User Journey

Home Page
→ Select City
→ Search Movie
→ View Movie Details
→ View Trailer
→ Compare Prices
→ Select Best Option
→ Redirect To Booking Platform

---

## Screen 1: Home Page

Purpose:
Allow users to search movies.

Components:
- Logo
- City Selector
- Search Bar
- Trending Movies
- Popular Movies

Actions:
- Select city
- Search movie

---

## Screen 2: Search Results

Purpose:
Display matching movies.

Components:
- Movie Poster
- Movie Title
- Rating
- Release Date

Actions:
- Open movie details

---

## Screen 3: Movie Details

Purpose:
Display complete movie information.

Components:
- Poster
- Backdrop
- Overview
- Cast
- Runtime
- Genres
- Ratings
- Trailer

Actions:
- Watch trailer
- Compare prices

---

## Screen 4: Price Comparison

Purpose:
Compare ticket prices.

Table Columns:
- Platform
- Theatre
- Ticket Price
- Convenience Fee
- Tax
- Discount
- Final Amount

Features:
- Cheapest option highlight
- Sort by price

Actions:
- Book now

---

## Screen 5: Redirect

Purpose:
Send users to booking platform.

Actions:
- Open external booking URL

---

## Mobile Design

Requirements:
- Responsive layout
- Mobile-first approach
- Touch-friendly controls
